### 新增功能

#### 1. 三阶段统一抓取脚本 (run_three_phases.py)

## 使用说明

### 执行三阶段抓取

```bash
# 终端1 - 执行抓取
python run_three_phases.py --skip-existing --force-retry

# 终端2 - 监控进度
python watch_progress.py
```

### 预期输出

**终端1**:
- 检测已完成的阶段并跳过
- 自动执行未完成的阶段
- 每个阶段完成后自动打包生成.zip
- 显示所有生成的zip文件和大小

**终端2**:
- 实时显示当前阶段
- 显示各源的抓取进度
- 显示当前正在抓取的URL
- 显示elapsed time

### 生成的技能包

完成后会生成以下文件：
- `output/spring-ai-starter.zip` (~1.5 KB)
- `output/spring-ai-official.zip` (~6.8 KB)
- `output/spring-ai-alibaba.zip` (~1.2 KB)

## 技术细节

### Progress文件格式

```json
{
  "task_name": "spring-ai-starter",
  "status": "running|completed|failed|timeout",
  "start_time": "2025-11-30 11:51:53",
  "last_update": "2025-11-30 11:51:59",
  "elapsed_seconds": 123,
  "phases": {
    "phase1_scraping": {
      "status": "completed",
      "sources": {
        "documentation": {
          "status": "completed",
          "progress": "45/100 pages",
          "elapsed_seconds": 90
        },
        "github": {
          "status": "completed",
          "progress": "Completed"
        }
      }
    },
    "phase2_conflict_detection": {"status": "completed"},
    "phase3_merging": {"status": "completed"},
    "phase4_building": {"status": "completed"}
  },
  "errors": [],
  "warnings": []
}
```

### Phase 3 (Merging) 逻辑

Phase 3只有在检测到冲突时才会执行：
- **有冲突**: status = "running" → "completed"
- **无冲突**: status直接标记为 "completed"（跳过）

watch_progress.py会智能检测并显示：
- `✅ Phase 3: Merging (completed - no conflicts detected)` - 无冲突跳过
- `✅ Phase 3: Merging (completed)` - 有冲突已合并
